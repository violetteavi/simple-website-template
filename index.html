I have been building robots since 2010. I started getting paid for it in 2017. I've worked on every facet of a robot, from the motor firmware to the world model to the end user interaction. Here's a few of the places I've worked, and what I did there.

Cornell University (Human-Robot Interaction, Control)

I graduated from Cornell University with a MS degree in computer science. While there, I conducted research on human-robot interaction for autonomous robots.

I fine-tuned a visual-language-action model (Pi0.5) for a pick-and-place task using AWS EC2. Then, I designed a user study to understand which failure modes have the greatest impact on a user's trust in the robot.

I adapted a mobile robot platform (the Clearpath Jackal) for GPS-denied indoor navigation to act as a guide during evacuation. I designed and ran a user study on how robot behavior impacts user compliance-- if they follow the robot to the exit, or leave the robot to collect their passport.

I adapted specification-driven control barrier functions for autonomous navigation of an emergency room. Then, I assisted my colleague Sandhya Jayaraman in conducting a user study on what feedback clinicians want from a robot.

Robust.AI (Perception, Control)

I integrated Google's Cartographer into the Stretch robot for 2D localization. I also wrote a design doc and automated testing suite for a tool to synchronize lidar, wheel odometry, and camera timestamps.

I wrote the firmware for a mecanum wheel drivetrain, including forward kinematics, wheel odometry from encoders, and serial-to-RS2232 communication.

MIT SPARK Lab (Perception)

I adapted Kimera, an open source metric-semantic VIO project, to live streams from the Intel d435i. You can see a live demo of real-time metric reconstruction here. I also automatically annotated camera feeds using an open source deep neural network.
